# 🚀 Desafio Github & Markdown


> Repositório oficial desenvolvido para consolidar os fundamentos de controle de versão, colaboração em equipe e documentação profissional utilizando Markdown, 

---

## 📋 Sobre o Desafio
Este projeto faz parte de um desafio prático focado em dominar o ecossistema Git e GitHub. O objetivo principal é exercitar o fluxo de trabalho colaborativo corporativo — desde a criação e configuração de um repositório remoto até a gestão de branches, abertura de *Pull Requests*, resoluções de conflitos e aplicação de boas práticas de segurança.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Git**: Sistema de controle de versão distribuído para rastreamento de alterações.
* **GitHub**: Plataforma de hospedagem de código e colaboração.
* **GitHub.dev**: Editor web integrado para edições rápidas no navegador.
* **Markdown**: Linguagem de marcação leve utilizada para criar documentações ricas.
* **Git Bash**: Interface de linha de comando para execução de comandos Git.

---

## 🗂️ Fluxo de Trabalho e Comandos Praticados

Durante o desenvolvimento deste desafio, foram aplicados os principais comandos do ciclo de vida do Git:

```bash
# 1. Clonar o repositório para o ambiente local
git clone [https://github.com/HigorCamposGit/desafio-github-markdown.git](https://github.com/HigorCamposGit/desafio-github-markdown.git)

# 2. Navegar até a pasta raiz do projeto
cd desafio-github-markdown

# 3. Criar e alternar para uma nova branch de desenvolvimento
git checkout -b feature/estruturacao-markdown

# 4. Verificar o status das alterações nos arquivos
git status

# 5. Adicionar arquivos modificados à área de stage
git add .

# 6. Registrar as alterações com um commit descritivo
git commit -m "docs: adiciona documentação profissional ao README.md"

# 7. Enviar a branch para o repositório remoto
git origin push feature/estruturacao-markdown

```
